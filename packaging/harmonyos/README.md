# 工作笔记：鸿蒙适配基础工程

目标：HUAWEI MatePad Pro Max 悦享款（用户提供型号 GEM-W40），HarmonyOS 7.0.0.109 SP6。

当前仅为 ArkTS 原生工程骨架与能力接入位置，**不是已完成的工作笔记应用，也不是可安装 HAP**。没有在本机安装 DevEco Studio / HarmonyOS SDK，没有编译、签名或真机验证，不能宣称与 Windows 版功能一致。

## 已准备

- 应用名称、标识、平板设备声明、图标和 Ability 入口。
- 鸿蒙 Web 容器装载现有界面的入口，以及工程开发状态页。
- 现有前端资源可通过 `scripts/prepare_harmonyos.py` 同步，统一保留 Windows 的界面和交互。
- 平台适配职责划分：数据库、选定数据目录权限、项目目录访问、文档提取、模型密钥、后台任务、签名及分发。

## 接入方式

1. 在 DevEco Studio 创建 API 26 的 Empty Ability、Stage 模型工程。
2. 使用 `com.worknotes.personal` 作为工程标识，将本目录中的 AppScope 与 entry 资源覆盖到新工程，保留 DevEco 生成的根级 hvigor、构建配置及依赖锁文件。
3. 同步前端资源。在 `entry/src/main/ets/platform/PlatformBridge.ets` 实现本机 API；在能力未实现前，页面会明确提示适配未完成，而不是静默改为连接 Windows 电脑或云端后台。
4. 模拟器预览不需要真机签名。进入真机阶段，由使用者本人完成个人开发者实名认证、开发者登录和设备绑定。
5. 合法调试签名包只用于绑定设备验证；向同事朋友分发的正式安装方式另行确认，仍保留用户离线安装要求。

## 尚未完成的业务适配

| 能力 | 实施要求 |
| --- | --- |
| 本地服务 | 实现与现有 `/api/*` 契约兼容的本机调用桥；禁止硬编码远程服务代替本地应用 |
| 数据 | 原有 SQLite 表、关系及历史迁移；用户选定目录与系统授权持久访问需真机核实 |
| 文件 | 系统文件选择器、授权 URI、项目目录读写及档案历史；不假定拥有 Windows 任意目录权限 |
| 文档 | Word/PPT/Markdown/PDF 提取能力，处理依赖与平台兼容，无法解析时明确反馈 |
| 模型 | 使用鸿蒙密钥存储；原 Windows DPAPI 密钥保留连接参数后重新填写；本地模型服务单独验证 |
| 调度 | 使用合适的系统任务能力并在恢复时补齐，不能简单复制 Windows 常驻 Python 服务 |
| 分发 | 合法签名与可用于普通平板用户的正式安装渠道；企业擎云 HEM 策略不适用于这台设备 |

此基础工程只用于后续开发，禁止将其作为鸿蒙正式版发送给其他用户。

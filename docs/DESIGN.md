# 工作笔记设计规范

2026-10-11（V2.1）：以用户确认的“编辑风”设计稿为准。纸白底色、细分割线组织、陶土色点缀、黑色实心主按钮，替代 V2.0 蓝灰主题。功能结构、菜单与业务规则不变，本轮仅视觉与版式。历史内容用于追溯，不作为当前视觉验收标准。

## 设计令牌

- 背景 `#FAFAF8`，卡片/编辑区 `#FFFFFF`，导航 `#F6F6F2`；正文 `#1B1B18`，辅助 `#54544D`，弱提示 `#8C8C83`，最弱 `#BCBCB3`。
- 分割线 `#E5E5DE`，浅线 `#EFEFEA`，深线 `#D9D9D1`；浅填充 `#F3F3EE`。
- 点缀陶土色 `#A4441F`（深色 `#8A3A1B`，浅底 `#FAF1EA`），仅用于导航当前项、重要紧急象限点、优先级选中、顺延提示、日历记录点、焦点环和链接。
- 主按钮黑色实心 `#1E1E1B`（悬浮 `#000`）；成功 `#4F7A45`、警告 `#A8762A`、错误 `#B03A2E`；圆角 8px。
- 字体栈 Inter/Segoe UI/PingFang SC/Microsoft YaHei；正文 13.5px/1.55，页面标题 26px/650。保留 `--muted`、`--subtle` 等旧别名映射到新令牌。

## 版式原则

- 全出血布局，无纸页外框与装饰阴影；用细分割线和留白分组，面板透明，减少嵌套卡片。
- 左侧 208px 导航：当前项 2px 陶土色左条 + 字重 600，无底色填充；窄屏折叠为图标，手机为底部六项导航、当前项顶部色条。
- 页面骨架固定：页头、正文独立滚动区、页脚三行；仅正文滚动。手机正文位于底部导航上方。
- 首页：目标两列（左列浅线分隔），“···”为 details 纯 CSS 弹层菜单；周日历选中为黑底白字圆形；昨日顺延为陶土浅底提示条；四象限为单个白色 14px 圆角容器，内部细线分格，象限点区分优先级；右栏随手记录常驻。
- 工作记录：月历日期 26px 圆形，选中黑底白字，有记录日期带 4px 陶土点；右列日详情。
- 重大汇报：单容器双编辑区，选中记录陶土浅底 + 左色条；会议 50/50、汇报 60/40；手机记录横向滚动、选中项底部色条。
- 弹窗 12px 圆角、细边框、轻阴影；输入焦点为陶土细环；动效限于入场与提示，尊重减少动态效果设置。
- 验收宽度：桌面 1440×900、1280×720，手机 390×844，极限 320×600；手机无水平溢出，底部导航不遮操作。

## 样式文件职责

- `static/base.css`：设计令牌与共享基元（按钮、输入、导航、页头、弹窗、提示、标签、文件夹选择、AI 预览）。
- `static/notebook.css`：页面布局（首页目标/日历/象限/待判断/随手栏、工作记录、项目管理、报告、设置、正文排版与桌面断点）。
- `static/dossier.css`：快速创建表单与项目档案内部。
- `static/experience.css`：固定框架、滚动区、图标、动效、中屏/手机/打印。
- `static/modern.css`：V2 模块（富文本编辑器、重大汇报、子事项、随手记录细节、文件目录、确认弹窗）与 V2 响应式/打印。
- 生成脚本依次合并 base → notebook → dossier → experience → modern 为 `static/style.css`；不要直接改生成文件。

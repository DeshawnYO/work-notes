# 工作笔记 2.4 功能修改

2026-10-13。产品版本2.4.0，沿用数据结构7，不新增团队共享。

## 今日工作：随手记录

新建输入框默认关闭，点击“记一条”展开并聚焦。点击保存后新增记录、清空草稿并收起输入框；空内容或失败保留输入。

已有记录点击“编辑”后，在当前记录位置显示富文本编辑器，原按钮改为“保存”。独立维护每条记录的编辑草稿，不把内容放进新建输入框；同页重绘及切换页面保留草稿，关闭程序时提醒未保存。取消修改需确认；保存检查原内容，避免覆盖另一页面的修改。

每条记录在编辑/保存按钮右侧提供“复制”，复制当前显示的内容，包括正在编辑的内容；支持富文本剪贴板，环境不支持时复制纯文本。复制不创建或修改记录。保留加入待办、图片、删除等原有能力。

## 工作报告

列表展示全部已保存报告，按创建时间倒序，显示周报/月报、报告期、创建时间；右箭头进入正文。移除列表中的历史任务状态卡片，生成状态在独立状态条显示，保留后台取消、失败重试及编辑保护。

统一入口“创建报告”：选择周报/月报、起止日期，再选择AI自动生成或手动创建。报告类型由用户选择，不按天数猜测。结束日期不得晚于今天、范围最多366天。

AI创建核对来源及模型后提交后台生成，保留2.3.2的工作事实汇总、按需查词和本地模型限制。手动创建进入空白正文编辑页，保存前不写入报告清单；正文不能为空，保存后可继续编辑及导出Markdown/Word。取消/离开时保护未保存正文。重复提交同一创建请求不重复生成或覆盖已保存内容。

## 全站与重大汇报

删除各页面底部“工作笔记 + 页码”组件，保留正文滚动与手机导航空间。

工作汇报的原“领导意见”区域改名“汇报结论”，原“补充说明”区域改名“领导意见”并默认折叠；已保存内容保留在原字段，不互换或删除。Word输出使用同样名称，已有Word不自动重写，用户再次保存Word时更新。重要会议的逐字稿/纪要及补充说明规则不变。

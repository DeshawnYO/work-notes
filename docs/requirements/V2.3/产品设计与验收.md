# 工作笔记V2.3项目需求管理

日期2026-10-13，版本2.3.0、数据结构5。仅增加项目需求管理；团队共享及版本规划暂存。

## 页面与字段

项目管理新增需求管理页签，每项目独立维护本机数据。字段包含固定编号、标题、类型、描述、优先级、状态、负责人、来源、计划日期、验收标准、处理结果、系统创建/更新/完成时间。

标题、类型必填。类型：功能需求、功能优化、Bug、技术改进、其他。优先级：紧急、高、中、低，默认中。状态：待确认、待处理、处理中、待验收、已完成、暂不处理，默认待确认。已完成必须填写结果，暂不处理必须填写原因；重开清空当前完成时间，历史保留。

表格末行连续添加，标题回车可提交；新增按钮及点击标题打开完整详情侧栏。未保存离开有保护。软删除可恢复，修订冲突拒绝覆盖。项目移出保留需求。

编号/标题/描述搜索，类型/状态/优先级/负责人组合筛选，更新时间/优先级/计划日期排序，每页30条。统计全部有效需求；列表数量为筛选结果。计划日期早于今天且未完成、非暂不处理时标延期。

## 一句话需求

按钮展开输入区。用户输入1—2000字并点击AI整理并创建，使用当前模型，成功自动入表并打开详情。模型提炼标题/类型/描述/验收建议，状态待确认、优先级中，负责人/日期/结果留空。保留原句，AI补充标待确认。仅发送填写描述，不扫描项目资料；展示模型发送边界。仅本地项目阻止云端、不自动切模型。失败或无效结构不入表、保留输入；相同请求重试去重，生成中保护切换/关闭。

## Excel

xlsx限10MB、10000数据行、60列；提供模板及枚举下拉。选择→字段对应→逐行校验/差异预览→确认→结果。标准表头自动对应，非标准表头手动对应，标题/类型必须对应。

无编号新增，有编号只更新当前项目有效需求；他项目/未知/已删除编号、同文件重复编号、非法枚举/日期/必填/公式列异常。同名新增提示，不自动合并，可排除单行。已对应选填空值清空，未对应字段保留，系统时间自动维护。

异常需修正或明确仅导有效行。确认前不写需求，提交重查修订，整批事务提交或撤销。预览24小时有效、一批只提交一次，提交后仍可下载异常清单。导出当前筛选或项目全部有效需求，覆盖全部分页和详细字段，保留中文多行与编号；文字不执行公式，无数据不生成文件。

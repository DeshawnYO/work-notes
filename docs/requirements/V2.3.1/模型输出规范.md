# 一句话需求模型输出规范

系统消息提供产品经理任务、字段约束和以下JSON示例；用户消息以任务对象附带需求描述，不仅发送原句。输出一个JSON对象，字段值全部为字符串。

```json
{
  "title": "支持按日期导出订单",
  "description": "在订单列表增加按日期导出功能，用于核对订单。导出字段待确认。",
  "type": "新功能",
  "system_name": "",
  "module_name": "",
  "status": "待开启",
  "priority": "P2",
  "source": "一句话需求",
  "proposed_date": "",
  "planned_date": "",
  "result": "待确认：导出字段及最大数据量。"
}
```

- title为需求名称，description为需求描述；其余未明确的信息为空字符串或采用默认值。
- type：新功能、功能优化、BUG修复、其他；priority：P0—P3，默认P2；status固定待开启。
- 系统、板块、排期仅提取用户明确的信息；提出时间由程序填写。补充建议标待确认，不推定已确认范围或已完成成果。
- 解析兼容中文字段、代码围栏及单条包装；不再强制验收建议。缺少非必要字段补默认值，缺描述以原句保底。结构异常最多修正一次，再失败保留输入。
- 生成成功保留原句并自动加入所选项目月份；序号由系统分配，同一请求不重复创建。

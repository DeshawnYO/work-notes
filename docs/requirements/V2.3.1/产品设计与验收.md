# 工作笔记2.3.1需求管理修复

日期2026-10-13，数据结构6。本版按用户安装2.3.0后的反馈修复，不含团队共享。

## 表格

字段顺序：序号、需求名称、需求描述、需求类型、所属系统、所属板块、状态、优先级、需求来源、提出时间、需求排期、备注。内部需求编号用于去重，不占可见业务列；Excel隐藏编号用于导回更新。

- 类型：新功能、功能优化、BUG修复、其他。
- 状态：待开启、设计中、待评审、开发中、测试中、试点中、已上线、已关闭。
- 优先级：P0、P1、P2、P3；默认P2，初始状态待开启。
- 类型、状态、优先级直接在表格下拉修改并保存。系统、板块手动输入，激活时可选择当前项目历月已有值；不同项目不互通。
- 新增操作行固定为第一条数据行，可以完整填写全部业务字段；点击添加或名称框回车保存。已有名称点击打开详情。
- 描述与备注支持多行，表格横向滚动查看全部字段。桌面固定序号和名称，手机固定序号。
- 提出时间默认今天，可手动修改；需求排期为可选日期。序号在项目每月内分配、不重复复用。

## 月度管理

默认本月；支持选择月份、上月/下月及返回本月。每月独立表格，历史记录可维护。

进入本月时，提示上月状态不是已上线、已关闭的有效需求；提供一键递延、选择需求、本月不递延。确认后本月不重复提示；稍后处理不记录确认。上月保留原记录，本月创建关联记录，保留原提出时间、描述及来源；两个月后续修改独立。目标月已有同一需求不重复加入。提交重新校验来源修订，整批成功或撤销。只允许递延到当前真实月份。

程序跨月时，正在查看上月且无草稿则切换本月；有未保存内容则保留并提醒。主动查看历史月份不自动跳转。

## 一句话需求

模型收到系统提示词中的完整JSON字段定义、枚举、空值规则及示例；用户描述包在任务对象中，不裸传。模型整理名称、描述、类型、系统、板块、优先级、来源、排期和备注，未明确的信息留空或标待确认；状态固定待开启，提出时间由系统填写。

兼容英文/中文字段、JSON代码围栏、单条包装对象/数组和说明中的JSON。非必要字段缺失采用默认值，不再强制要求验收建议。描述缺失时保留原始描述；结构无法解析时最多修正一次，仍无效则保留输入、不创建半成品。来源、原句和AI待确认补充保留，同请求去重。遵守本地模型限制，不扫描项目或发送历史需求。

## Excel与升级

导入导出使用新字段及枚举，按选定月份进行。说明页记录月份；带月份文件只允许导回对应月份，编号只更新当前项目该月需求。旧表头/枚举可导入并转换，原负责人/验收标准隐藏保留。序号由目标月份分配，隐藏编号保持稳定。保留预览、差异、事务提交、公式保护和异常下载。

迁移6按旧需求创建月份归档，新增系统、板块和提出时间；类型与优先级映射至新枚举，待确认/待处理→待开启，处理中→开发中，待验收→测试中，已完成→已上线，暂不处理→已关闭。原负责人、验收标准及迁移前完整快照保留，可在详情查看原版信息。旧预览失效，需要重新校验；不删除需求或原文件。

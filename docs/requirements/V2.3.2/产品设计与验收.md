# 工作笔记 2.3.2 报告生成修复

2026-10-13，数据结构7。按用户反馈修复周报/月报生成，不增加团队共享。

## 生成范围

用户选择起止日期并核对来源后提交。保留原有报告期、历史状态、来源快照和模板规则；仅以工作记录、事项、推进条目、重大汇报等为工作证据。随手想法、目标标为参考，不能写成已完成成果。已有会议纪要优先于重复发送原始转写。

初始请求只包含工作证据、项目名称/ID及模板，不读取档案、项目背景或目标说明。少量证据一次生成；大量工作证据分批提炼，不截掉范围内的记录。整理时新写入的事项不混入已提交的来源快照。

## 按需释义

系统提示词约定：模型通常直接生成正文；仅当工作事项中的名词或歧义阻碍准确表达时，返回 `action=lookup`、项目ID、关键词及原因。服务只查询有本期工作证据的项目，不接受任意文件路径或其他项目ID。

每轮最多3项查询、每项3个关键词，最多2轮；读取《项目档案.md》中命中关键词的片段，每项目查询最多2400字、本次总计8000字，保留出处行号。重复查询不重复读取。没有命中或达到上限时写待确认；释义不能新增本期成果。保留项目仅本地处理限制，每次云端调用前重新检查。

## 后台状态

提交后立即关闭生成弹窗，工作报告页显示任务状态，其他页面显示可收起的状态条。不会自动切换页面，不锁住新增事项或已有报告编辑。

同一提交去重，一次只运行一项报告任务。状态：排队中、运行中、取消中、成功、失败、已取消、已中断。显示阶段、等待时间及错误；成功可查看/导出，失败可重新核对后提交。刷新页面继续显示任务；完整退出程序会中断，重开后提示重新生成。

取消在当前模型调用返回或超时后结束，不保存半成品。单次模型调用整体80秒、整个报告任务最多10分钟；失败、超时及格式修复无效均保留已有报告和工作记录。默认模板格式最多修正一次。生成期间模板改变则停止，请用户按新模板重试。

完成后仅刷新报告索引及状态，保留当前页面、焦点和未保存正文。新报告及来源快照与成功状态同时提交。旧报告不会被替换。

迁移7仅新增报告任务表及索引，重复执行不影响旧报告。后台任务存本机数据库；任务接口不返回来源快照或模型密钥。保留本机访问和会话校验。

# 目录说明

公开仓库保留当前源码、必要构建与启动脚本、品牌资源、第三方依赖许可、项目和开发文档，以及按版本组织的安装包索引。保留 GitHub 共创模板和必要源码检查；不保留无关测试脚本、验证数据、旧截图、构建日志与历史设计副本。

| 目录 | 用途 | GitHub |
| --- | --- | --- |
| 根目录 Python、static、scripts、packaging | 当前源码与必要运行/构建入口 | 提交 |
| assets、vendor | 当前品牌资源、运行依赖与第三方许可证 | 提交 |
| docs | 当前开发、设计、需求方向、目录与发布规范 | 提交 |
| releases/windows/<版本> | 本地原包、说明、发布信息、校验和许可 | 提交说明；原包上传 Releases |
| .github | 共创模板和源码语法/样式检查 | 提交 |
| archive | 历史测试、验收、设计、生成构建目录及旧说明 | 本地归档 |
| .local | 发布工具、账号配置及本次临时工作目录 | 本地忽略 |
| data、发布准备/个人迁移备份 | 真实数据和备份 | 本地保留，禁止上传 |
| dist | 日常便携程序、运行时及可能的工作资料 | 本地保留，禁止上传 |
| build/tools、build/downloads | 构建工具及下载缓存 | 本地保留，禁止上传 |

2026-10-12 整理将无关资料移入 archive/20261012-本地整理，目录内整理清单记录原路径。当前开发目录无需解压旧档案。未修改真实数据、备份或日常程序；历史安装包仅规范路径，不重建、不覆盖。

根目录源码保留现有布局，避免破坏模块导入、启动入口和打包路径。vendor/pypdf、启动/迁移脚本、构建工具仍被使用，不能作为无关测试文件删除。
